# 폐기한 회고 초안

`/memory-update` 에서 검토한 뒤 **안 남기기로 한** 후보를 한 줄씩 기록한다.
회고 잡(`reflect.py`)과 `/memory-update` 가 이 목록을 읽어 **같은 초안을 또 만들지 않는다**.

초안을 폐기하면 `_pending/` 의 파일이 지워진다. 그러면 거절했다는 사실이 어디에도 안 남아서,
다음 세션이 같은 트랜스크립트를 읽고 같은 교훈을 뽑아 같은 초안을 또 만든다. 사람은 또 버린다.

**금지 목록이 아니다.** 그 사이 같은 일이 반복돼 값어치가 생겼으면 다시 올려도 된다 —
대신 무엇이 달라졌는지를 함께 적는다. 그래서 만료 규칙이 따로 없다.

**추가 전용**이다. 지우거나 고치지 않는다. 오래된 항목은 상한(50건) 밖으로 자연히 밀려난다.

형식 — `- \`<slug>\` — <왜 안 남겼는지 한 줄> (<날짜>)`
